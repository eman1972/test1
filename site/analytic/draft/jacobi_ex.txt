\section{作用}

　実例抜きで理論ばかりやっていると、
理想ばかりを語っているようで、
この話は一体どこまで現実に適用可能な話なのかと不安になってくる。
　それで、ここでは幾つかの典型的な例をまとめて紹介しておくことにしよう。

　目的は 2 つあって、
ここまで説明した手続きが「それほど現実離れした難しいものではないよ」というのを
実感してもらうことと、
ここまで説明した話が「いつでも綺麗に実行できるほど簡単なわけでもないよ」というのを
実感してもらうことである。
　矛盾しているようだが、そんなものだ。
　書いている私としては、「こんな単純なことを説明するだけなのに、
なぜこんなにも面倒くさい事が多いんだ！」という気持ちだ。

　第 4 部のここまでの内容をすんなり理解できていたとしても、

\section{デカルト座標での自由粒子}

　まずは最も簡単そうな例として、
3 次元空間にある自由な一粒子のハミルトニアンについて試してみよう。

<tex>
H = \frac{1}{2m} ( p_x^2 + p_y^2 + p_z^2 )
</tex>

　座標変数を含まないのでとてもシンプルだ。
　これは次のような方程式になる。

<tex>
\frac{1}{2m} \left[ \left(\pdif{S}{x}\right)^2 + \left(\pdif{S}{y}\right)^2 + \left(\pdif{S}{z}\right)^2 \right]\ =\ E
</tex>

　右辺が定数であるので、左辺のカッコの中の各項はそれぞれが定数でないとおかしい。
　いや、そうとも言い切れないかも知れない。
　しかし、もし左辺の各項で定数以外の変数が残ったとすると、
それぞれは 2 乗の形になっているため、他の項とうまく打ち消すなんて事もないだろう。
　それで、

<tex>
S = X(x) + Y(y) + Z(z) + k
</tex>

という形になっており、

<tex>
\dif{X}{x} = a \ ,\ \ \ \dif{Y}{y} = b \ ,\ \ \ \dif{Z}{z} = c
</tex>

が成り立っているのだろう。
　これ以外の形を思い付けるだろうか？
 $ a $、$ b $、$ c $は任意定数だが、完全に自由なのではなく、

<tex>
\frac{1}{2m}( a^2 + b^2 + c^2 )\ =\ E
</tex>

を満たしていなくてはならない。
　この結果、

<tex>
X(x) &= ax + k'  \\
Y(y) &= by + k'' \\
Z(z) &= cz + k'''
</tex>

のようになり、まとめると、

<tex>
S = a x + b y + c z + k
</tex>

ということだが、最後についている任意定数$ k $は
今回の理論に関係しないので省いてしまってもいいだろう。

<P>

　ここで、新運動量$ \Vec{P} $の成分は$ ( a, b, c ) $だと解釈する。

\section{極座標での自由粒子}

　第 1 の例では座標変数を含んでいないので簡単すぎた。
　極座標を使えば、座標変数を含んだハミルトニアンが作れる。
　しかし物理的内容は全く同じだ。

<tex>
H = \frac{1}{2m}\left( p_r^2 + \frac{1}{r^2} p_\theta^2 + \frac{1}{r^2 \sin^2 \theta} p_\phi^2 \right)
</tex>

　なぜこのように表せるのか、説明しておいた方がいいだろうか。
　これは単なる計算例なのだから細かいことは気にしないでもいいのだが、
簡単なので説明しておこう。

<P>

　今の場合、ポテンシャルエネルギーは 0 であり、
運動エネルギーだけを考えればいいのでラグランジアン$ L $は、

<tex>
L &= \frac{1}{2}m( \dot{x}^2 + \dot{y}^2 + \dot{z}^2 ) \\
  &= \frac{1}{2}m( \dot{r}^2 + r^2 \dot{\theta}^2 + r^2 \dot{\phi}^2 \sin^2\theta )
</tex>

となる。
　一方、一般化運動量は

<tex>
p_r\ &=\ \pdif{L}{\dot{r}}\ =\ m\dot{r} \\
p_{\theta}\ &=\ \pdif{L}{\dot{\theta}}\ =\ mr^2 \dot{\theta} \\
p_{\phi}\ &=\ \pdif{L}{\dot{\phi}}\ =\ mr^2 \dot{\phi} \sin^2 \theta
</tex>

である。
　ハミルトニアンは、今回の場合は運動エネルギーのことなので、
上の$ L $と同じになるのだが、
それを今求めた一般化運動量を使って表してやっただけである。
　さあ、では今回の例の本題に入ろう。
　解くべき偏微分方程式は次のようなものである。

<tex>
\frac{1}{2m}\left[ \left(\pdif{S}{r}\right)^2 + \frac{1}{r^2} \left(\pdif{S}{\theta}\right)^2 + \frac{1}{r^2 \sin^2 \theta} \left(\pdif{S}{\phi}\right)^2 \right] \ =\ E
</tex>

　今度の例では各偏微分が定数であるべきだとは言えない。
　むしろ各項の偏微分の結果に座標変数が残って、
他の変数を打ち消す形になってくれていなければ、
右辺が定数であることと合わないのだ。
　しかしハミルトニアンの中に座標変数$ \phi $が含まれていないことから、
正準方程式を根拠にして、$ \dot{p}_\phi = -\pdif{H}{\phi} = 0 $であることが分かる。
　つまり、$ p_\phi $は一定値$ c $だということだ。
　それで、$ \pdif{S}{\phi} = c $となるべきだということだけは読み取れる。
