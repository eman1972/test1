\section{第3章}

　第 2 章では二準位系で成り立つ理論をある程度まとめた。
この章ではそれを拡張する形で$ N $準位系の理論を構成することにしよう。
結果として$ N $準位系の理論になるのであって、初めから$ N $準位系の理論を狙うわけではない。
とは言うものの、第 2 章で 2 次の正方行列を使っていたものを$ N $次の正方行列に拡張すればそうなるというのはだいたい想像が付いている。

<P>

　密度行列$ \hat{\rho} $というのは対角和が 1 であるようなエルミート行列だった。
この条件を保ったまま行列の次数を$ N $にしたとき、
その中には実数何個分の情報を詰め込むことが出来るだろうか？

<P>

　エルミート行列の対角成分は実数でなければならないので、まず$ N $個ある。
非対角成分は全体から対角成分を引いて$ N^2 - N $個あるが、実部と虚部があるのでこの 2 倍の実数が使われる。
しかし対角成分を挟んで対称な位置にある成分どうしは複素共役になっているからその半分、つまり$ N^2 - N $である。
合計すると$ N^2 $個である。
しかし対角和が 1 だという制限があるので、対角成分の最後の 1 個だけは他の成分によって自動的に決められてしまう。
結局は$ N^2 - 1 $個の実数を入れることが出来るということになる。

<P>

　第 2 章では$ N=2 $だったので 3 個分のスピンの期待値の情報を入れることができたのである。

<P>

　第 2 章では$ \sigma_i $という記号を使っていたが、
この章ではスピンのイメージから離れるために$ \lambda_i $という記号を使って議論することにしよう。
特に何であるかを指定しない何らかの物理量を表す記号であってスピンもその中に含まれる。
スピンを$ x,y,z $軸のそれぞれの軸で測ったときの期待値を$ \langle \sigma_i \rangle $と表していたように、
何らかの物理量を何らかの異なる方法で測ったときの期待値を$ \langle \lambda_i \rangle $と表すことにしよう。

<P>

　$ \hat{\rho} $を$ N $次に拡張すれば、
それらの期待値は次のような定義によって$ N^2 - 1 $個まで$ \hat{\rho} $の中に詰め込むことが出来るはずである。

<tex>
\hat{\rho} \ =\ \frac{1}{N} \left( \hat{I} \ +\ \sum_{i=1}^{N^2-1} \langle \lambda_i \rangle \, \hat{\lambda}_i \right) \tag{1}
</tex>

　ただし、ここで次のような条件に従う$ N^2-1 $種類の行列$ \hat{\lambda}_i $を導入した。

<tex>
&\hat{\lambda}^{\dagger}_i \ =\ \hat{\lambda}_i \tag{2} \\[5pt]
&\mathrm{Tr}\Big[ \hat{\lambda}_i \Big] \ =\ 0 \tag{3} \\[5pt]
&\mathrm{Tr}\Big[ \hat{\lambda}_i \, \hat{\lambda}_{j} \Big] \ =\ N \, \delta_{ij} \tag{4}
</tex>

　例えば$ N=3 $の場合、これらは 8 種類もあるのである。
残念ながら$ N=2 $のパウリ行列のようなきれいな交換関係は成り立っていない。
うまく選べばこのうちの幾つかの行列どうしがそれに似た関係を満たすようにすることもできるのだが、
$ N=2 $の場合とは違って必ずそうなるというわけではない。

<P>

　(1) ～ (4) 式のように定義すべき理由は第 2 章でほとんど説明してしまったが、念の為にざっと説明を繰り返そう。
(1) 式の$ \hat{I} $は$ \hat{\rho} $の対角和を 1 にするために入っている。
他の行列$ \hat{\lambda}_i $の対角和は (3) 式によってどれも 0 だと制限してあるので$ \hat{I} $を入れて調整するしかないのである。
$ \hat{I} $の対角和は$ N $になるので、全体を$ N $で割って調整している。
(1) 式において全てを大きなカッコの中に入れているので、(4) 式の右辺に$ N $を置くことで調整をしている。
それは次のような単純な式でうまく期待値$ \langle \lambda_i \rangle $の値を$ \hat{\rho} $の中から取り出せるようにするためである。

<tex>
\langle \lambda_i \rangle \ =\ \mathrm{Tr}\Big[\hat{\rho}\hat{\lambda}_i\Big] \tag{5}
</tex>

　全てはこの式のために用意されたという感じである。

\section{条件の意味}

　次の話に入る前に、この (2) ～ (4) 式のような条件を満たす$ N^2 - 1 $個の行列$ \hat{\lambda}_i $の組をちゃんと選べる保証があるのかどうかを考えてみよう。
結論から言えば、あるから安心して欲しい。
さらに言えば、きっかり$ N^2 - 1 $個までしか選べない。

<P>

　まず、今回とは関係のない行列の積の対角和について考えてみよう。
全ての成分が実数のみの行列$ \hat{A} $と$ \hat{B} $がある場合、$ \mathrm{Tr}[^{t}\hat{A}\hat{B}] $という計算をすると、
同じ位置にある全ての成分どうしを掛け合わせたものの合計の値が求まる。
まるで行列の成分を全て一列に並べて作ったベクトルどうしの内積を計算しているかのようである。
面白いので知らなかった人は確かめてみてほしい。

<P>

　複素ベクトルどうしの内積というのは一方の複素共役を取ってから計算をする必要があるのだった。
そうしないと自分自身との内積が実数になってくれないので大きさが決まらず、内積として機能しないからである。
よって、複素成分を持つ行列$ \hat{A} $と$ \hat{B} $がある場合、$ \mathrm{Tr}[(^{t}\hat{A})^\ast \hat{B}] $という計算をすれば、
あたかも全ての成分を並べて作った複素ベクトルどうしの内積のイメージとなる。
つまり、$ \mathrm{Tr}[\hat{A}^\dagger \hat{B}] $である。

<P>

　ということは、もし行列$ \hat{A} $や$ \hat{B} $がエルミート行列ならば
$ \mathrm{Tr}[\hat{A}\hat{B}] $という計算をするだけで同じ意味になっているわけだ。
実はそれだけではない。
この計算結果は必ず実数になっているのである。
エルミート行列の同じ位置にある要素どうしを掛けているのだから、
ある位置の要素どうしの積と、その対象位置の要素どうしの積とは互いに複素共役になっており、全ての和を取ったときに虚部が打ち消されてしまうのである。
（なお、このことはエルミート行列どうしの積がエルミート行列になるとは限らないこととは矛盾しない。
話を混ぜてしまいそうになるが、計算内容が違っているのである。）

<P>

　さて、$ \hat{\lambda}_i $というのは対角和が 0 であるようなエルミート行列であり、
$ N^2 - 1 $個の実数の組み合わせによって決まるものである。
しかもそれらの線形和もまた「対角和が 0 であるようなエルミート行列」であるから、
$ N^2 - 1 $次元空間内に散らばるベクトルのようなものである。
(4) 式の左辺はそれらどうしの内積を定義しているのである。
異なる行列どうしでその値が 0 になるというのは互いに直交していることを表しているし、
同じ行列どうしでは値が$ N $になるというのは規格化を行っているのである。

<P>

　こういう状況であるから、$ N^2-1 $個の直交基底を選ぶことが可能である。
具体的にはグラムシュミットの直交化法を使って決めてやることも出来る。

<P>

　この見方をすると、(3) 式の条件にも同じような意味が見いだされる。
(3) 式は単位行列と全ての$ \hat{\lambda}_i $とが直交しているという意味になるだろう。
そうすると、ここまでの説明とは少し違う説明も可能になる。
対角和が 1 であるという条件のないエルミート行列には実数$ N^2 $個分の自由度があって、
そこに単位行列を含む$ N^2 $個の直交基底を導入したのだという見方をしてもいいだろう。

\section{パウリ行列に相当するもの}

　第 2 章ではパウリ行列が特別ではないという話をして主役の座から引きずり下ろすことをしたのだった。
しかしパウリ行列が最も分かりやすい形をしていて扱いやすかったのは否定できない。
今回のように$ N $次の行列に拡張した場合には、$ \hat{\lambda}_i $として具体的にどんな形の行列の組を選ぶのが最も分かりやすくて合理的だろうか？

<P>

　$ \hat{\lambda}_i $はエルミート行列なので、その対角成分は必ず実数である。
そして対角和が 0 であるという制限が掛かっているので$ N - 1 $個の成分を自由に選べることになる。

<P>

　「対角行列」と「対角成分が全て 0 である行列」とは (4) 式の意味で互いに直交しているので、
対角行列を$ N-1 $個作って互いに直交するように選んで、
残りの全ては「対角成分が全て 0 であるような行列」にしてしまおう。
そのように分けるのが最も整理されている感じになって良いだろう。

<P>

　ところが、これだけの方針では唯一に定まらないのである。
$ N=2 $の場合には対角行列はただ一つだったし、
条件の数と成分の数も同じだったので、成分の値は 1 と -1 に自動的に定まった。
それが$ \hat{\sigma}_z $である。

<P>

　$ N=3 $以上では少しばかり美意識にも頼って決めてやる必要がある。
$ N=3 $では対角行列は 2 つ作ることが出来て、例えば次のような組み合わせが考えられる。

<tex>
\sqrt{\frac{3}{2}}
\left(
\begin{array}{ccl}
1 & 0 & 0 \\
0 & 0 & 0 \\
0 & 0 & \!\!\!\!-1 
\end{array}
\right)
\ \ \ , \ \ \ 
\sqrt{\frac{1}{2}}
\left(
\begin{array}{ccc}
1 & 0 & 0 \\
0 & -2 & 0 \\
0 & 0 & 1 
\end{array}
\right) \tag{6}
</tex>

　とにかく、一般的には$ N-1 $個の対角行列$ \hat{\lambda}_a $を用意できるのであり、
それらの成分を次のように表すことにしよう。

<tex>
\hat{\lambda}_a \ =\ 
\left(
\begin{array}{cccc}
\lambda_a(1) & 0 & 0 & 0 \\[5pt]
0 & \lambda_a(2) & 0 & 0 \\[2pt]
0 & 0 & \ddots & 0 \\[5pt]
0 & 0 & 0 & \lambda_a(k)
\end{array}
\right) \tag{7}
</tex>

　(3) 式と (4) 式の条件を満たすためにはこれらの要素は次のような関係を満たしていなくてはならない。

<tex>
\sum_{k=1}^{N} \lambda_a(k) \ =\ 0 \tag{8}
</tex>

<tex>
\sum_{k=1}^{N} \lambda_a(k) \, \lambda_{a'}(k) \ =\ N \, \delta_{aa'} \tag{9}
</tex>

　対角行列というのは大変に扱いが楽であって、固有ベクトルは次のような$ N $個である。

<tex>
\ket{1} = \left( \, \begin{array}{c} 1 \\ 0 \\ 0 \\ \vdots \\ 0 \end{array} \, \right) \ \ , \ \ 
\ket{2} = \left( \, \begin{array}{c} 0 \\ 1 \\ 0 \\ \vdots \\ 0 \end{array} \, \right) \ \ , \ \ 
\cdots \ \ , \ \ 
\ket{N} = \left( \, \begin{array}{c} 0 \\ 0 \\ \vdots \\ 0 \\ 1 \end{array} \, \right) \tag{10}
</tex>

　ここで第 2 章のスピンの例にならって物理的解釈を行ってみよう。
$ \lambda_a $という何らかの物理量の観測を行い、
$ \lambda_a(k) $という値を得ることによって観測対象が$ \ket{k} $という状態にあることを知る。
全部で$ N $個の状態があり、そのうちのいずれかが確率的に得られるのである。

<P>

　$ N-1 $個の対角行列に相当する何らかの物理量があって、それらは状態$ \ket{k} $が決まれば同時に値を確定することが可能である。
どの物理量にとっても固有ベクトル$ \ket{k} $は共通であり、同じ状態を共有していると言えるからである。

<P>

　ここで物理量の観測値という概念が怪しく思えてくる。
$ \lambda_a(k) $というのは (8) 式や (9) 式の条件を満たすようにという制限の中で自由に決めたのだった。
現実の観測値とはリンクしていないのである。

<P>

　スピンの値でも実測されるのは$ \pm \hbar/2 $である。
しかし第 2 章ではその状況を仮に$ \pm 1 $という測定値を使って理論を組み立ててみたのだった。
実のところ、実験の仕方によって得られる値は幾らでも変えられる。
本質的に重要なところは、$ N $個の区別できる状態があって、
測定値によってどの状態であるのかが判断できるという部分だけである。

<P>

　今作ろうとしているのは、どうやら、得られる測定値を予言するような理論でもないし、
測定値の分布の仕方に制限を与えるようなものでもないようだ。
本当にそういう話に向かおうとしているのか、もう少しあれこれ考えて行こう。

\section{期待値と確率}

　ここまでに対角行列$ \hat{\lambda}_a $に対応する$ N-1 $個の物理量の話はしたが、
全部で$ N^2 - 1 $個の行列$ \hat{\lambda}_i $があってそれらに対応する物理量もあるはずである。
しかし$ N-1 $個の物理量に限定して話すと理論構造が分かりやすくなるので、
もうしばらくは$ N-1 $個の物理量だけを使って話を進めてみよう。

<P>

　(5) 式では$ \hat{\rho} $の中に格納してある期待値の情報を取り出すことしか出来ていないのだった。
しかし本当は「ある指定した状態が観測される確率」が得られる方がありがたいのである。
期待値というのは多数の観測値の平均値のようなものであって、
せっかくの多数の情報が均されてしまっている感じがする。
期待値から確率の値を復元することは出来るだろうか？

<P>

　期待値というのは次のようにして計算できるのだった。

<tex>
\langle \lambda_a \rangle \ =\ \sum_{k=1}^{N} \lambda_a(k) \, p(k) \tag{11}
</tex>

　ここで$ p(k) $というのは、対象が取り得る$ N $個の状態のうち、
$ k $番目の状態であることが測定によって判明する確率である。
　確率の合計は 1 にならないといけないので、次のように表せる。

<tex>
\sum_{k=1}^{N} p(k) \ =\ 1 \tag{12}
</tex>

　今、我々は$ p(k) $を知りたいと思っている。
$ k $は$ 1 \sim N $の$ N $通りあるので、$ p(k) $は$ N $個の未知数であるが、
(12) 式によって最後の一つは勝手に決まるので$ N-1 $個の未知数である。
一方、期待値$ \langle \lambda_a \rangle $の方も$ N-1 $個あって、(11) 式は$ N-1 $個の条件式である。
未知数の数と条件式の数が一致している一次式なので、$ p(k) $を求めることが出来るはずである。
やってみよう。

<P>

　この状況を行列で表してやると次のようになる。

<tex>
\left( \begin{array}{c}
\langle \lambda_1 \rangle \\
\langle \lambda_2 \rangle \\
\vdots \\
\vdots \\
\langle \lambda_{N-1} \rangle \\
1
\end{array}
\right)
\ =\ 
\left( \begin{array}{cccc}
\lambda_1(1) & \lambda_1(2) & \cdots & \lambda_1(N) \\
\lambda_2(1) & \lambda_2(2) & \cdots & \lambda_2(N) \\
\vdots       & \vdots       &        & \vdots       \\
\vdots \\
\lambda_{N-1}(1) & \lambda_{N-1}(2) & \cdots & \lambda_{N-1}(N) \\
1            & 1            & \cdots & 1
\end{array}
\right)
\left( \begin{array}{c}
p(1) \\
p(2) \\
\vdots \\
\vdots \\
p(N-1) \\
p(N)
\end{array}
\right) \tag{13}
</tex>

　この右辺の$ N $次の正方行列の逆行列を求めて両辺に掛けてやれば$ p(k) $を得る式が得られるはずである。
そこでこの行列の中身を見てやると、どの横一列も$ N-1 $個の対角行列の対角成分を並べたものになっている。
 (9) 式の条件によってこれらは大きさ$ \sqrt{N} $の互いに直交するベクトルのようなものであると分かる。
よって行列全体を$ \sqrt{N} $で割ってやれば、大きさ 1 の直交するベクトルが横並びになっていることになる。
こういう構造を持つ行列は直交行列と呼ばれるのだった。
直交行列というのは転置行列が逆行列なので、それを両辺にかけてやれば良い。
そのためにまず (13) 式の両辺を$ \sqrt{N} $で割ってやって、
それから、直交行列と化した部分の転置行列を両辺に掛けるのである。
結果的に左辺を$ \sqrt{N} $で 2 回割る形になるから、次のようになるだろう。

<tex>
\frac{1}{N}
\left( \begin{array}{ccccc}
\lambda_1(1) & \lambda_2(1) & \cdots & \lambda_{N-1}(1) & 1 \\
\lambda_1(2) & \lambda_2(2) & \cdots & \lambda_{N-1}(2) & 1 \\
\vdots       & \vdots       &        & \vdots           & \vdots \\[-3pt]
\vdots       & \vdots       &        & \vdots           & \vdots \\[-3pt]
\vdots       & \vdots       &        & \vdots           & \vdots \\
\lambda_1(N) & \lambda_2(N) & \cdots & \lambda_{N-1}(N) & 1 
\end{array}
\ \right)
\left( \begin{array}{c}
\langle \lambda_1 \rangle \\
\langle \lambda_2 \rangle \\
\vdots \\
\vdots \\
\langle \lambda_{N-1} \rangle \\
1
\end{array}
\right)
\ =\ 
\left( \begin{array}{c}
p(1) \\
p(2) \\
\vdots \\
\vdots \\
p(N-1) \\
p(N)
\end{array}
\right) \tag{14}
</tex>

　この行列計算の内容を書き直せば、次のような式が導かれる。

<tex>
p(k) \ =\ \frac{1}{N}\left( 1 + \sum_{a=1}^{N-1} \lambda_a(k) \, \langle \lambda_a \rangle \right) \tag{15}
</tex>

　さて、(5) 式を使えば$ \hat{\rho} $から$ \langle \lambda_a \rangle $を取り出すことができるのだったから、
この (15) 式の中の$ \langle \lambda_a \rangle $の部分をそれに置き換えてやれば$ \hat{\rho} $から確率$ p(k) $を得る式が作れるだろう。
しかし、対角和の線形性や$ \mathrm{Tr}[\hat{\rho}] = 1 $であることを利用してやれば、
(15) 式とほとんど同じ形のまま対角和の中に放り込んだような次の形にしてやることもできる。

<tex>
p(k) \ =\ \mathrm{Tr} \left[ \hat{\rho}\ \frac{1}{N}\left( \hat{I} + \sum_{a=1}^{N-1} \lambda_a(k) \, \hat{\lambda}_a \right) \right] \tag{16}
</tex>

　こうして目的は果たすことが出来たのだが、この式はごちゃごちゃしていて公式としては使い勝手が悪い。
実はこれをきれいに書き換える方法があるのだ。
まず、$ \hat{\lambda}_a $はスペクトル分解によって次のように表すことが出来る。

<tex>
\hat{\lambda}_a \ =\ \sum_{k=1}^{N} \lambda_a(k) \, \ket{k} \bra{k} \tag{17}
</tex>

　完全性により、次の式も成り立っている。

<tex>
\sum_{k=1}^{N} \ket{k} \bra{k} \ =\ \hat{I} \tag{18}
</tex>

　ここで少し前に出てきた式を見てやると、(11) 式と (12) 式は、(17) 式と (18) 式と同じ形をしているのだ。
$ p(k) $だったものを$ \ket{k} \bra{k} $に置き換えて、$ \langle \lambda_a \rangle $を$ \hat{\lambda}_a $に置き換えればいい。
(11) 式と (12) 式から (15) 式が得られたのだから、同じ方法で同じ係数を得ることが出来るはずであり、
次の結果を得ることになる。

<tex>
\ket{k} \bra{k} \ =\ \frac{1}{N}\left( \hat{I} + \sum_{a=1}^{N-1} \lambda_a(k) \, \hat{\lambda}_a \right) \tag{19}
</tex>

　この (19) 式は (16) 式の中にある部分とそっくり同じである。
(16) 式でややこしく書かれている部分を$ \ket{k}\bra{k} $ですっかり置き換えてやることが出来て、次のようになる。

<tex>
p(k) \ &=\ \mathrm{Tr} \Big[ \hat{\rho} \ \ket{k} \bra{k} \Big] \\[3pt]
&=\ \mathrm{Tr} \Big[ \bra{k} \hat{\rho} \ket{k} \Big] \\[5pt]
&=\ \bra{k} \hat{\rho} \ket{k} \tag{20}
</tex>

　こうして、簡単な公式によって$ \hat{\rho} $の中から確率の情報を取り出せることが分かった。

<P>

　ここまでの話に出てきたような、
$ N $個の状態ベクトル$ \ket{k} $を基底に選んで行う測定のことを「\red{基準測定}」と呼ぶことにしよう。

<P>

　さて、美しい簡潔な数式が導かれては来たものの、
多くの読者はこの辺りで再び不満を感じ始めるのではないだろうか。
相変わらず、理論と現実とがリンクする感じが得られないままである。
例えば、現実に考えられる様々な測定のうちのどれが基準測定だと考えればいいのだろうか？

<P>

　このような不満の原因は、\red{実はまだ隠している話があるせい}なのだ。
しかしこの時点でそれを話してしまうと読者の意識がそちらを向いてしまい、
さらなる疑問が生じて混乱させてしまうかもしれないのでわざと黙っている。
ここまでの話は前提が曖昧なままで進んできており、それが後ほど明らかになる予定である。
申し訳ないけれども、もうしばらくは違和感に耐えていただきたい。

\section{一般の測定}

　読者の不満を感じながらもさらに話を広げて行こう。
基準測定以外の測定でも同様な公式が得られるかどうかという話をして行きたい。

<P>

　第 2 章の二準位系では、唯一の基準測定であった$ \hat{\sigma}_z $の他に
$ \hat{\sigma}_x $や$ \hat{\sigma}_y $があったのだった。
しかし、これから話す「基準測定以外の測定」というのはそれらにとどまらない。
どんな角度で測定した場合を考えてもいいのだ。
実を言うと、それ以外のもっと広い状況をも含んでいるのだが、その話は後にしておこう。

<P>

　これまでに様々な測定を表す$ \hat{\lambda}_i $というものを考えてきたが、
それらは色んな条件で縛られていたのだった。
しかし今はそういう条件には従わないような一般の測定まで考えたいのである。
それは$ \hat{\lambda}_i $と同じくエルミート行列で表せるものだと考えて、
$ \hat{\Lambda} $という記号で表すことにする。
条件はそれだけであって、対角和が 0 であるべしという条件すら課さないことにする。

<P>

　$ \hat{\Lambda} $は$ N $次のエルミート行列であるから、
最大$ N $個の互いに直交する固有ベクトルを持つだろう。
固有値が異なる場合にはそれらは自動的に互いに直交する形になっているが、
そうでない場合でも直交するように選んでやることができる。
これらの$ N $個の固有ベクトル$ \ket{u_k} $が、
この測定をしたときの結果として得られる$ N $通りの状態のいずれかを表しているということにする。

<P>

　$ \ket{u_k} $は互いに直交する$ N $個のベクトルであり、
基準測定の$ \ket{k} $も互いに直交する$ N $個のベクトルであるからには、
これらは何らかのユニタリ行列によるユニタリ変換でつなげてやることができる。
ユニタリ行列は互いの直交関係を崩さないような変換なのだった。

<tex>
\ket{k} \ =\ \hat{U} \, \ket{u_k} \tag{21}
</tex>

　物理学者が何もかもを「ユニタリ変換」と呼ぶせいで混乱してしまうかもしれないが、
これこそ本当の意味でのユニタリ変換である。
あくまでベクトルどうしがユニタリ変換で結ばれると言っているだけであって、
測定を表す演算子$ \hat{\lambda}_a $と$ \hat{\Lambda} $が「ユニタリ行列による相似変換」で結ばれるとは言っていない。

<P>

　さて、これを見ると反射的に (21) 式を (20) 式に代入してやりたくなるのだが、
そうしてみてもまるで意味が分からない次のような式が得られるだけである。

<tex>
p(k) \ =\ \bra{u_k} \hat{U}^{\dagger} \hat{\rho} \, \hat{U} \ket{u_k} \tag{22}
</tex>

　この変な式の意味を何とか考えてみようか。
これは相変わらず、基準測定を実行したときに、$ \ket{k} $という状態が得られる確率を意味しているだけである。
ただし、無理やり$ \hat{U} $で$ \ket{u_k} $と対応付けた$ \ket{k} $という状態が得られる確率である。
今はそんな無意味な式が欲しいわけではないだろう。
欲しいのは$ \ket{u_k} $という状態が得られる確率である。
それを得るためにはもう少し物理的な状況を考慮する必要がありそうだ。

<P>

　第 2 章のスピンの測定を参考にして考えてみよう。
スピンでは基準測定を$ \hat{\sigma}_z $として設定したのだった。
そしてそれ以外の測定というのは、装置の角度をあれこれ変えてみた上で$ \hat{\sigma}_z $と同様の手段で状態を調べるというものだった。
つまり、装置の角度を変えた時点で、その装置にとっての観測対象の状態を表す$ \hat{\rho} $の中身が変わっていて、
その新しい状態$ \hat{\rho}' $に対して基準測定を行っているのだと考えられるのではないだろうか。
この状況を式で表すと次のようになる。

<tex>
p(k) \ &=\ \bra{k} \hat{\rho}' \ket{k} \\
&=\ \bra{u_k} \hat{U}^{\dagger} \hat{\rho}' \, \hat{U} \ket{u_k} \tag{23}
</tex>

　では$ \hat{\rho}' $はどのように変わっていると考えればいいだろうか？ 
残念ながら数学的な論理や測定の定義などをこねくり回すことでは解決できそうにない。
旧来の量子力学の論理を借りてこないといけなくなってしまうからである。
現在の我々の方針に従うのならば次のように考えるしかない。
\red{第 2 章で行ったスピンについて成り立っていた論理を含むような理論にするにはどうしたらいいだろうか、と。}
そう考えるなら、もう話は簡単である。
次のように決めてやればいい。

<tex>
\hat{\rho}' \ =\ \hat{U}\,\hat{\rho}\,\hat{U}^{\dagger} \tag{24}
</tex>

　この$ \hat{U} $というのは、「測定する装置の角度を変える」だとか「外部磁場を加える」だとか、
観測を伴わないそういった物理的操作に対応しているのだと解釈することにする。
この解釈が成り立つかどうかは実験による検証が必要であるが、問題が見付かったりはしていないようである。
この (24) 式を (23) 式に代入してやれば次のような単純な、ちょっと見覚えのある形の式を得ることが出来る。

<tex>
p(k) \ &=\ \bra{u_k} \, \hat{\rho} \, \ket{u_k} \tag{25}
</tex>

　この式を得たいがために、(24) 式のようであるべきだろうと推論したのである。
これは第 2 章で得た式を含むものであり、その一般化になっている。

<P>

　念の為にちょっと復習をしておくと、もし観測対象が純粋状態$ \ket{\psi} $であるならば$ \hat{\rho} = \ket{\psi}\bra{\psi} $と表せて、
この式は次のように書き換えることが出来るのである。

<tex>
p(k) \ &=\ \bra{u_k} \, \big( \ket{\psi}\bra{\psi} \big) \, \ket{u_k} \\[3pt]
&=\ \braket{u_k|\psi} \braket{\psi|u_k} \\[3pt]
&=\ \braket{u_k|\psi} \braket{u_k|\psi}^{\ast} \\[3pt]
&=\ |\braket{u_k|\psi}|^2 \tag{26}
</tex>

　状態$ \ket{\psi} $が状態$ \ket{u_k} $へと遷移する確率を求める式であり、「\red{ボルン則}」と呼ばれているものである。
それで、この教科書では純粋状態でなくとも成り立つ (25) 式のような形であっても広くボルン則と呼んでいる。

\section{一般の測定の期待値}

　上の方では期待値というのはせっかくの情報を均してしまっていてもったいない気がするということを書いたのだったが、
今からそのもったいないことをしようと思う。
一般の測定の観測確率$ p(k) $を求める方法を知ったのだから、それを使って物理量$ \Lambda $の期待値$ \langle \Lambda \rangle $を得る公式を作っておこう。

<P>

　まず、物理量$ \Lambda $を表す演算子$ \hat{\Lambda} $はスペクトル分解によって次のように表せる。

<tex>
\hat{\Lambda} \ =\ \sum_{k=1}^{N} \Lambda(k) \, \ket{u_k} \bra{u_k} \tag{27}
</tex>

　ただし、$ \Lambda(k) $というのは$ k $番目の固有値である。
固有値というのは$ \ket{u_k} $という状態になったときに得られる観測値でもあるのだった。

<P>

　次に、期待値$ \langle \Lambda \rangle $というのは確率$ p(k) $と観測値$ \Lambda(k) $を組み合わせて次のように計算できるのだった。

<tex>
\langle \Lambda \rangle \ =\ \sum_{k=1}^{N} \Lambda(k) \, p(k) \tag{28}
</tex>

　形がよく似ているけれども、まだ結びつかない。

<P>

　さて、$ p(k) $については先ほど公式を得たが、次のように書き換えることもできる。

<tex>
p(k) \ &=\ \bra{u_k} \, \hat{\rho} \, \ket{u_k} \\
&=\ \mathrm{Tr} \Big[ \hat{\rho} \ket{u_k} \bra{u_k} \Big] \tag{29}
</tex>

　材料は出揃った。
あとは組み合わせればいいだけだ。
(29) 式を (28) 式に代入して、対角和というのは線形性が成り立つので係数も対角和の中に入れてしまって (27) 式を使って書き換えればいい。
その通りにやってみせよう。

<tex>
\langle \Lambda \rangle \ &=\ \sum_{k=1}^{N} \Lambda(k) \, p(k) \\[3pt]
&=\ \sum_{k=1}^{N} \Lambda(k) \, \mathrm{Tr} \Big[ \hat{\rho} \ket{u_k} \bra{u_k} \Big] \\[3pt]
&=\ \mathrm{Tr} \left[\hat{\rho} \, \sum_{k=1}^{N} \Lambda(k) \, \ket{u_k} \bra{u_k} \right] \\[3pt]
&=\ \mathrm{Tr} \left[\hat{\rho} \hat{\Lambda} \right] \tag{30}
</tex>

　このように、物理量の演算子$ \hat{\Lambda} $と$ \hat{\rho} $を掛けて対角和を取れば期待値が得られるし、
物理量の射影演算子$ \ket{u_k} \bra{u_k} $と$ \hat{\rho} $を掛けて対角和を取れば確率$ p(k) $が得られる。
第 2 章で暗中模索であれこれ試してみた規則が大きなルールの中に綺麗に収まっていくのを感じてもらえると嬉しい。

\section{一般の測定とは何か}

　我々はこれまで演算子$ \hat{\lambda}_i $について幾つかの制限を入れてきたのだが、
一般の測定の演算子$ \hat{\Lambda} $についてはエルミート行列であること以外にそのような制限は無いのだった。
固有値が幾つであってもここまでの話が成り立つ。

<P>

　例えばスピンの測定についてはこれまで ±1 という値を使ってきたが、$ \pm \hbar/2 $を使ってもいいのである。
それどころか、それに定数を加えたものを使ってもいい。
例えば +3 と +1 という固有値を持つ二準位系を考えればその演算子は例えば次のようになるだろう。

<tex>
\left(\ \begin{array}{cc} 3 & 0 \\[3pt] 0 & 1 \end{array} \ \right) \tag{31}
</tex>

　これでも固有ベクトルは$ (1,0) $と$ (0,1) $であり、これまでの議論と変わらない。
そういう演算子$ \hat{\Lambda} $を使ってもいいのである。

<P>

　例えば三準位系においては 1, 0, -1 という 3 つの固有値を使って議論すべきなのではないかと思うかもしれないが、
一般の測定においてはそのような制限もない。
例えば 5, 4, -1 という不規則な 3 つの固有値を持つ測定を扱ってもいいのである。
この場合$ \hat{\Lambda} $は例えば次のように表せるだろう。

<tex>
\left(\ \begin{array}{ccc} 5 & 0 & 0 \\[3pt] 0 & 4 & 0 \\[3pt] 0 & 0 & -1 \end{array}\ \right) \tag{32}
</tex>

　これでも固有ベクトルは$ (1,0,0) $、$ (0,1,0) $、$ (0,0,1) $の 3 つであり、
固有値が違うだけであり、議論の内容は変わらない。
これをユニタリ行列で相似変換したものを使った場合にはそれに合わせて固有ベクトルも変わるけれども、そういうものを使ってもいいわけである。

\section{取り残された演算子の意味}

　さて、話を少し戻そう。
全部で$ N^2-1 $個の行列$ \hat{\lambda}_i $があったのだった。
そして、それら内の$ N-1 $の対角行列の話は既にしたのだった。
すると、あと$ N^2 - N $個の行列$ \hat{\lambda}_i $の話が残っているはずである。
しかし今、あらゆる一般の測定の話をまとめてしまったのだから、もうそれらの行列$ \hat{\lambda}_i $の出番は無いではないか。
それらには一体どんな意味があるのだろう？

<P>

　ここで議論をひっくり返す必要がある。
ここまで密度行列$ \hat{\rho} $から情報を取り出すための公式などを説明してきたけれども、
その密度行列$ \hat{\rho} $はそもそも誰が準備したものだっただろうか？
どうやって？

<P>

　そう問い直すと最初の方の議論の意味が見えてくる。
$ N^2-1 $個の行列$ \hat{\lambda}_i $というのは密度行列$ \hat{\rho} $を作るために必要なのである。
それらの行列に相当する測定を準備して、無限回の測定を行い、
期待値$ \langle \lambda_i \rangle $を割り出して (1) 式の定義に従って密度行列を作成する。
そのようにして出来た$ \hat{\rho} $は測定対象についてのすべての情報を持っている！

<P>

　$ \hat{\lambda}_i $は測定値を予言しているわけでも制限しているわけでもない。
全情報を得るために必要になる測定の組み合わせの例を決めてくれていたのだ。
そのような測定の組み合わせで$ \hat{\rho} $を完成させて測定対象の全ての情報を得ることを「\red{量子情報トモグラフィ}」と呼ぶ。

<P>

　どうしてこんな騙し討ちのような説明順序になってしまったかについて考えてみて欲しい。
我々は一般の測定の話に到達するまでは、測定とは何かということをうまく理解できていなかった。
仮の理論的な足場として基準測定という概念を必要としていた。
これは新しい概念を学ぶときにはよく起こることである。
既存の量子力学に頼らないで進もうとする我々にとって、密度行列は全くの新しい概念である。
それは既存の概念とは関係なく、土台無しに宙に浮いているようなものだから、
仮設の足場を組んでやって騙し騙し議論をして、無事に渡り終えた後で外してやることが必要になる。

<P>

　測定対象についての本質的な情報が含まれているのは$ \hat{\rho} $であって、
演算子$ \hat{\Lambda} $については測定者の都合、装置の組み方次第、目盛りの付け方次第でどうとでも準備できるのである。
測定値というのは実は測定対象が持っている情報ではない。
本質的な情報とは、どの状態がどんな確率で得られることになるのかということだけである。
測定値はそれぞれの状態を区別するために測定者側が工夫して用意した手掛かりに過ぎない。

<P>

　第 2 章でスピンという具体例から話を始めたために、$ N $準位系においても具体的な何かが得られると期待させてしまったかもしれない。
しかし今やろうとしているのは、あらゆる測定で成り立つ理論の枠組みを決めることである。
ある程度の理論の一般化に成功した今となっては、もはや二準位系であってもスピンに限った話ではないのである。
スピンではユニタリ行列$ \hat{U} $が空間的に回転させて測定をすることに対応していたが、
具体的などんな操作がどんな$ \hat{U} $に対応しているかを理論的に明らかにすることはできない。
それは個々の対象によって違っている可能性があるからだ。

\section{密度行列の固有値}

　密度行列$ \hat{\rho} $を使った新しい理論の世界へようこそ。

<P>

　次の章へ移る前に、密度行列$ \hat{\rho} $について少し話しておこうと思う。
第 2 章で既に説明してあるが、密度行列の固有値は複数の状態の重ね合わせの確率を意味しているのだった。
確率の和は 1 にならなければならないので、固有値の和は 1 にならなければならない。
対角和というのは固有値の合計に等しいので、$ \hat{\rho} $の対角和は 1 になるようにしてあるのである。
ここで言っているのは量子力学的な重ね合わせのことではなく、
観測者が目の前に置かれている対象系の状態を完全には知っていないという状況を表すものである。

<P>

　この章では$ N $準位系に拡張したのだからそれを前提にした形で再び同じような説明を入れておこう。
$ N $準位系においては$ \hat{\rho} $の固有値$ q_k $は$ N $個あるから、スペクトル分解によって次のように表せる。

<tex>
\hat{\rho} \ =\ \sum_{k=1}^N q_k \, \ket{\psi_k}\bra{\psi_k} \tag{33}
</tex>

　これは目の前に複数の状態のうちのどれかの状態$ \ket{\psi_k} $が置かれており、どの状態が置かれているかは毎回確率$ q_k $によって決まり、
観測者はどの状態が置かれているかを知っていないという状況と等価である。
これを「\red{混合状態}」と呼ぶのだった。

<P>

　もし固有値のうちの一つだけが 1 で残りが全て 0 ならば、観測者は目の前に置かれている量子状態$ \ket{\psi} $を正確に知っていることを意味している。
この場合には$ \hat{\rho} = \ket{\psi}\bra{\psi} $と書けるのである。
この状態を「\red{純粋状態}」と呼ぶのだった。

<P>

　さて、ここで疑問が生まれる。
もし$ N $個以上のそれぞれ異なる量子状態$ \ket{\psi_k} $を確率的に持って来られていたとしたらどうなるだろうか？
$ m $種類の状態$ \ket{\psi_k} $を確率的に観測者の目の前に置くことにしてみよう。
その場合にも$ \hat{\rho} $は次のように表せばいいのである。

<tex>
\hat{\rho} \ =\ \sum_{k=1}^{m} q_k \, \ket{\psi_k}\bra{\psi_k} \tag{34}
</tex>

　実は観測者の目の前に持ってくる$ \ket{\psi_k} $は$ \hat{\rho} $の固有状態である必要もない。
このような式で作った$ \hat{\rho} $は固有値を$ N $個までしか持てないので、
結局は (33) 式のようなスペクトル分解によって最大$ N $個の状態の重ね合わせとして書き直されることになる。
要するに、実際に用意したのとは別の状態の重ね合わせであると解釈されるわけだ。
どんな風に準備しようと$ \hat{\rho} $が同じになるのであれば観測者にとってはどれも等価であって、
観測によって決して違いを見抜くことは出来ない。
ということは、観測者にとっては$ \hat{\rho} $こそが観測対象から得られる情報の全てなのだ。


<P>

　そう言えば、何らかの物理的操作を行うことによって$ \hat{\rho} $は違った形に変わるという話をしたのだった。
何か都合の悪いことが起きたりしないだろうか？
心配は要らない。
(24) 式のような変換はまさに「ユニタリ行列による相似変換」であって、変換前後で固有値はまったく変わらないのである。
だから物理的操作によって状態の確率的な重ね合わせの割合が変わるなどといったおかしなことは起きない。
観測しない限りは純粋状態が混合状態に変わったり、混合状態が純粋状態に変わったりはしないのである。

<P>

　まだまだ心配は尽きない。
ここまでに話したような解釈が成り立つためには$ \hat{\rho} $の固有値は全て正の値でないといけないのだ。
ところが、$ N^2-1 $個の$ \langle \lambda_i \rangle $を使って$ \hat{\rho} $を作る際には
わざわざそのような配慮をしていないのだった。
必ずその条件が満たされるという保証はあるのだろうか？

<P>

　それについては簡単に証明が出来るので安心してほしい。
既に説明したように、基準測定の期待値の組から確率の組を逆算することが出来るのだった。
$ \langle \lambda_i \rangle $は現実の観測から得ている数値なので確率は必ず正の値になるはずである。
よって (20) 式により$ \bra{k} \hat{\rho} \ket{k} \geq 0 $が言える。
この$ \ket{k} $を任意の$ \hat{U} $によって任意の$ \ket{\psi} $に変換する物理的操作があるはずであり、
$ \bra{\psi} \hat{\rho}' \ket{\psi} \geq 0 $が言える。
$ \ket{\psi} $が任意であるということは、$ \hat{\rho}' $の固有ベクトル$ \ket{\psi_k} $を使っても成り立っているはずであり、
次のようにして固有値が正であることが分かる。

<tex>
\bra{\psi_k} \hat{\rho}' \ket{\psi_k} \ &\geq \ 0 \\[5pt]
\therefore\ \bra{\psi_k} q_k \ket{\psi_k} \ &\geq \ 0 \\[5pt]
\therefore\ q_k \braket{\psi_k|\psi_k} \ &\geq \ 0 \\[5pt]
\therefore\ q_k \ &\geq \ 0 \tag{35}
</tex>

　$ \hat{\rho}' $は$ \hat{\rho} $の相似変換であるから固有値は変わらないままであり、固有値は正であることが分かる。

<P>

　まだまだ色んな話ができるが、残念な話をひとつして終わりにしよう。
$ N=2 $の場合にはブロッホ球というものを考えて、その表面が純粋状態に相当し、内部が混合状態に相当するという視覚的イメージを使うことが出来た。
しかし$ N \geq 3 $の場合にはそのような分かりやすいものが使えない。
$ N^2-1 $個の$ \langle \lambda_i \rangle $の組み合わせが$ N^2-1 $次元の球の一定半径以内に収まる範囲に存在することだけは言えるのだが、
その球の表面や内部の全ての点に相当する状態がどれでも存在するわけではないことも証明できてしまうのである。
